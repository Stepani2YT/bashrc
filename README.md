Изменение приглашения (PS1) в bash

Переменная окружения PS1 отвечает за внешний вид приглашения командной строки.

Пример простого изменения:
bash

export PS1="[\u@\h \W]\$ "

Где:

    \u — имя пользователя
    \h — имя хоста
    \W — текущая директория (только последний компонент)
    \$ — символ $ для обычного пользователя и # для root

Чтобы сделать изменение постоянным, добавьте эту строку в файл ~/.bashrc.
Пример с цветом
bash

export PS1="$$\e[32m$$\u@\h:\w\$ $$\e[0m$$"

Это сделает приглашение зелёным.

Если вы имели в виду что-то другое — уточните, пожалуйста!
как добавить приветствие в терменале

Чтобы добавить приветствие в терминале, вы можете использовать файл конфигурации вашей оболочки. В зависимости от используемой оболочки (например, bash, zsh и т.д.) процесс может немного отличаться. Вот как это сделать для наиболее распространённых оболочек:
Для Bash

    Откройте файл ~/.bashrc:
    bash

nano ~/.bashrc

Добавьте строку с приветствием в конец файла. Например:
bash

echo "Добро пожаловать в терминал, $(whoami)!"

Сохраните изменения и закройте редактор (в nano нажмите CTRL + X, затем Y, чтобы подтвердить сохранение, и Enter).

Примените изменения:
bash

    source ~/.bashrc

Теперь при каждом запуске терминала будет выводиться ваше приветствие.
Для Zsh

    Откройте файл ~/.zshrc:
    bash

nano ~/.zshrc

Добавьте строку с приветствием в конец файла:
bash

echo "Добро пожаловать в терминал, $(whoami)!"

Сохраните изменения и закройте редактор.

Примените изменения:
bash

    source ~/.zshrc

Пример более сложного приветствия

Если вы хотите сделать приветствие более информативным, вы можете использовать команды для отображения даты или времени:
bash

echo "Добро пожаловать, $(whoami)! Сегодня $(date '+%A, %d %B %Y')"

Это выведет имя пользователя и текущую дату.

Теперь при каждом открытии терминала будет отображаться ваше приветствие! Если у вас есть дополнительные вопросы или нужны другие примеры, дайте знать!
как добавить красное приглошение в терменале

Чтобы добавить красное приглашение (prompt) в терминале, вы можете изменить переменную окружения PS1, которая отвечает за внешний вид строки ввода. Вот как это сделать для различных оболочек, таких как bash и zsh.
Для Bash

    Откройте файл ~/.bashrc:
    bash

nano ~/.bashrc

Добавьте или измените строку с переменной PS1. Например, чтобы сделать приглашение красным, добавьте следующую строку:
bash

export PS1="$$\e[31m$$\u@\h:\w\$ $$\e[0m$$"

Здесь:

    $$\e[31m$$ — устанавливает красный цвет.
    \u — имя пользователя.
    \h — имя хоста.
    \w — текущая директория.
    \$ — символ $ для обычного пользователя и # для root.
    $$\e[0m$$ — сбрасывает цвет обратно к стандартному.

Сохраните изменения и закройте редактор (в nano нажмите CTRL + X, затем Y, чтобы подтвердить сохранение, и Enter).

Примените изменения:
bash

    source ~/.bashrc

Теперь ваше приглашение должно отображаться красным цветом.
Для Zsh

    Откройте файл ~/.zshrc:
    bash

nano ~/.zshrc

Добавьте или измените строку с переменной PROMPT. Например:
bash

export PROMPT="%{$fg[red]%}%n@%m:%~%# %{$reset_color%}"

Сохраните изменения и закройте редактор.

Примените изменения:
bash

    source ~/.zshrc

Теперь ваше приглашение в Zsh также должно отображаться красным цветом.
Примечание

Если вы хотите использовать другие цвета, вы можете заменить код цвета в строках на другие значения:

    30: черный
    31: красный
    32: зеленый
    33: желтый
    34: синий
    35: пурпурный
    36: циан
    37: белый

Как изменить цвет в  echo ""

Чтобы изменить цвет текста, выводимого с помощью команды echo, вы можете использовать специальные escape-последовательности ANSI. Вот как это сделать:
Основные цвета

Вот некоторые основные коды цветов:

    30: черный
    31: красный
    32: зеленый
    33: желтый
    34: синий
    35: пурпурный
    36: циан
    37: белый

Пример использования

Чтобы вывести текст красным цветом, вы можете использовать следующую команду:
bash

echo -e "\e[31mВаш текст здесь\e[0m"

Объяснение

    -e: позволяет интерпретировать escape-последовательности.
    \e[31m: устанавливает красный цвет текста.
    Ваш текст здесь: это текст, который вы хотите вывести.
    \e[0m: сбрасывает цвет обратно к стандартному.

Примеры других цветов

Вот несколько примеров для разных цветов:

    Зеленый текст:
    bash

echo -e "\e[32mЭто зеленый текст\e[0m"

Желтый текст:
bash

echo -e "\e[33mЭто желтый текст\e[0m"

Синий текст:
bash

echo -e "\e[34mЭто синий текст\e[0m"

Пурпурный текст:
bash

echo -e "\e[35mЭто пурпурный текст\e[0m"

Циановый текст:
bash

echo -e "\e[36mЭто циановый текст\e[0m"

Белый текст:
bash

    echo -e "\e[37mЭто белый текст\e[0m"

Фоновый цвет

Если вы хотите изменить фон текста, используйте коды от 40 до 47:

    40: черный фон
    41: красный фон
    42: зеленый фон
    43: желтый фон
    44: синий фон
    45: пурпурный фон
    46: циановый фон
    47: белый фон

Пример с фоновым цветом:
bash

echo -e "\e[41;37mТекст на красном фоне с белым шрифтом\e[0m"
